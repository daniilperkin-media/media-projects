Gothic Character Project

A gothic novel's visual, grown one generation at a time: AI-built character reference sheets, scene compositions and pose experiments — kept like an archive rather than a folder. A pure-stdlib toolchain recovers whatever text metadata the generators left behind, three manifests keep every library PNG accounted for, and a five-step gate stands between a new file and the shelf. The prompting bible — visual markers, never names; diegetic sound only; no brands — is enforced, not aspirational.

The character bible, enforced

Three canon characters, one rule for all of them: describe by visual markers, never by name. The chips are the canonical marker sets from PROMPTS.md; the prompt is editable, and the linter re-runs its four rules on every keystroke. The library, sheet to scene

Canon starts on the model sheets; scenes rebuild the same markers at story scale. Every capture is a downscaled copy of a tracked PNG — nothing re-rendered for the web. Both sets stay still — the library and the pose comparison — so every capture can be read side by side.
