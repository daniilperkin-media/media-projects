Gothic Character Project

A gothic novel's visual, grown one generation at a time: AI-built character reference sheets, scene compositions and pose experiments — kept like an archive rather than a folder. A pure-stdlib toolchain recovers whatever text metadata the generators left behind, three manifests keep every PNG accounted for, and a five-step gate stands between a new file and the shelf. The prompting bible — visual markers, never names; diegetic sound only; no brands — is enforced, not aspirational.

The character bible, enforced

Three canon characters, one rule for all of them: describe by visual markers, never by name. The chips are the canonical marker sets from PROMPTS.md; the sentence beside them is built from those markers alone. The linter runs the project's four prompt rules — names, brands, structure, audio — and the violating draft is there to show what a fail looks like.

The library, sheet to scene

Canon starts on the model sheets; scenes rebuild the same markers at story scale. Every capture is a downscaled copy of a tracked PNG — nothing re-rendered for the web.

One pose, four takes

The Demoness' signature pose, tested across six files and three engines until it held. The manifest records which takes keep the exact floor-sit and which drift from it.

The gate — five checks, no exceptions

Every change must pass

python -m compileall -q .
python extract_png_metadata.py --strict
git diff --exit-code -- '*_metadata.txt'
git ls-files --others -- '*_metadata.txt'
python validate_manifests.py

Corruption, a drifted sidecar, an uncommitted sidecar or a manifest mismatch fails the build — the same five steps run in CI on every push.

What the generators left behind

Most AI generators ship PNGs scrubbed of their text chunks — empty extractor output is the norm here, and the manifests say so instead of guessing. Five files kept something: raw EXIF, and one job ID that outlived its prompt.

The inspector replays the extractor's real verdicts, file by file. The five recovered sidecars are committed, LF-pinned and byte-identical — the gate fails if any drifts by a single byte. Tool: extract_png_metadata.py.
